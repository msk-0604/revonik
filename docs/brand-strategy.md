# REVONIK ブランド戦略の整理（提案用）

株式会社Stark Lab による公式サイト提案のための整理です。**事実**（公開情報で確認できた内容）と**仮説・提案**（Stark Lab の見立て。REVONIK との協議で確定する）を分けて記載しています。出典は `src/data/*.ts` の `source(s)` に記録しています。

## 1. ブランドの独自性

| 区分 | 内容 |
| --- | --- |
| 事実 | ダイワ精工（現グローブライド）・ラッキークラフト・ジャッカルでルアー開発に携わった加藤誠司氏が、2023年に立ち上げたブランド。 |
| 事実 | 「自分だけが釣れるルアーを作らない」（記事見出しで本人の言葉として紹介）。 |
| 事実 | 素材の制約を構造で超えるアプローチ（Dot SIX：肉厚約0.6mm・分割成形、SaraMoa：樹脂化＋ラトル入り構造）。 |
| 事実 | 「音」へのこだわり（硬質素材ドライボーン、ガラスラトル）。 |
| 提案 | **「設計思想が見えるルアーブランド」**として、製品ごとの「なぜこの形か」を伝えることを中核に据える。 |

## 2. 想定する顧客層（仮説）

- **コアファン**：加藤誠司氏の過去作（TDバイブレーション、ベビーシャッドなど）を知るベテランのバスアングラー。設計者の考え方や開発背景に価値を感じる。
- **ハードベイト志向の中級者**：レンジやシーンでルアーを使い分けたい層。比較情報（レンジ・タイプ）を求める。
- **取扱店・メディア**：新製品情報や製品の要点を正確に把握したい層。

## 4. 顧客が購入する理由（仮説）

1. **設計者への信頼**：実績あるデザイナーが手がけていること。
2. **明確な役割**：レンジ・シーンごとに「この状況ならこれ」と選べる。
3. **構造の独自性**：薄肉・重心移動・ドライボーンなど、他にない理由がある。

## 5. 他ブランドとの差別化要素（提案）

- 大手の網羅的なラインナップではなく、**少数精鋭の製品それぞれに設計の物語がある**ことを前面に。
- 製品ページで「なぜこの形か（Design Details）」「どう使い分けるか（Action & Performance）」を必ず示す。
- 開発者本人の言葉・動画（公式 YouTube／擬似餌研究所）と製品を結びつける。

## 6. ブランドとして伝えるべき価値（提案）

> **「その一投に、理由がある。」**（提案コピー）

すべての形・素材・音に設計上の理由があり、それが釣り人の一投を支える——この価値を、サイト全体（Hero → 製品体験 → 設計 → 実釣 → ブランドストーリー → 比較 → ストア）で一貫して伝える。
